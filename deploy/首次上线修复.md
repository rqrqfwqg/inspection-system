# inspection-system · 首次上线修复命令（服务器 82.156.62.59）

> 巡检发现：代码是新的，但**服务从未运行**——9527 未监听、无 app.db、nginx 没配 /ops/、无 .env。
> 本文档按 P0 → P1 顺序一次修完，全部在服务器终端执行（app.db 需从本机 scp）。
>
> **两个和 `deploy/` 里教程不同的关键修正**（照抄原教程会失败）：
> 1. **不要装 `deploy/nginx-inspection.conf`** —— 它引用的 `/etc/nginx/ssl/inspection.crt` 不存在，
>    且 443 端口已被物料系统占用，新建 server 会冲突。正确做法是**在现有 443 的 server 块里插一个 `location /ops/`**，
>    沿用现有证书。
> 2. **后端不再监听 0.0.0.0** —— 已改为读 `BACKEND_HOST`，默认 `127.0.0.1`。
>    这样 9527 物理上不对公网开放，比改 ufw 更彻底（DISABLE_AUTH 免登录的风险同时被消解）。

## 第 2 步 · 写 `.env`（补齐 JWT 密钥与管理员密码，修 P1-4）

```bash
cd "$(readlink -f ~/inspection-system)/backend"
JWT_KEY=$(openssl rand -base64 48 | tr -d '\n')
ADMIN_PW=$(openssl rand -base64 24 | tr -d '\n')
cat > .env <<EOF
JWT_SECRET_KEY=${JWT_KEY}
ADMIN_INIT_PASSWORD=${ADMIN_PW}
DEV_MODE=false
DISABLE_AUTH=true
BACKEND_HOST=127.0.0.1
PORT=9527
EOF
chmod 600 .env
echo "管理员初始密码: ${ADMIN_PW}"     # ← 记下来，只显示这一次
```

> 密钥每次部署随机生成，不会写进任何文档/仓库。改 `.env` 后需 `sudo systemctl restart inspection`。

> `DISABLE_AUTH=true` = 内网免登录（现场扫码便利）。因为后端只绑 127.0.0.1，
> 公网无法直连 9527，配合 nginx 443 才可达。若要强制登录改为 `false`（用上面的管理员密码）。

## 第 7 步 · 用 systemd 托管启动（修 P0-1）

```bash

sudo tee /etc/systemd/system/inspection.service > /dev/null <<EOF

Description=Inspection System Backend (FastAPI)
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=${REAL}/backend
Environment="PATH=${REAL}/backend/venv/bin:/usr/bin:/bin"

Restart=always
RestartSec=5
StandardOutput=append:${REAL}/backend/server.log
StandardError=append:${REAL}/backend/server.log

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable inspection
sudo systemctl restart inspection
```

## 第 8 步 · nginx 插入 `/ops/` 反代（修 P0-3）

先找到现有 443 配置文件：

```bash
sudo grep -rl "listen 443" /etc/nginx/sites-enabled/ /etc/nginx/conf.d/ 2>/dev/null
```

假设输出 `/etc/nginx/sites-enabled/tools`（以实际为准，下面用 `$CONF` 指代）：

```bash
CONF=/etc/nginx/sites-enabled/tools          # ← 改成上一条命令的实际输出
sudo cp "$CONF" "$CONF.bak.$(date +%Y%m%d_%H%M)"

# 在 server { 后插入 location /ops/（放在 location / 之前）
sudo python3 - "$CONF" <<'PY'
import sys, re
p = sys.argv[1]
s = open(p, encoding="utf-8").read()
if "/ops/" in s:
    print("已存在 /ops/ 配置，跳过"); sys.exit(0)
block = '''    location /ops/ {
        proxy_pass http://127.0.0.1:9527;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Prefix /ops;
        proxy_redirect off;
        proxy_read_timeout 120s;
        client_max_body_size 50m;
    }

'''
# 插到第一个 location / 之前；没有则插到 server 块首行之后
m = re.search(r"^(\s*)location\s+/\s*\{", s, re.M)
if m:
    s = s[:m.start()] + block + s[m.start():]
else:
    m2 = re.search(r"server\s*\{", s)
    s = s[:m2.end()+1] + "\n" + block + s[m2.end()+1:]
open(p, "w", encoding="utf-8").write(s)
print("已插入 location /ops/")
PY

sudo nginx -t && sudo systemctl reload nginx
```

## 第 9 步 · 收紧防火墙（修 P1-5）

